# Changelog

All notable changes to this research artifact are documented here.

## [1.0.0] - 2026-08-06

### Added

- Initial public research release with 181 terminology records.
- Spreadsheet and machine-readable JSON representations.
- Annotation guideline in DOCX and PDF formats.
- PURA final report in DOCX and high-fidelity three-page PDF formats.
- Dataset card, methodology, annotation schema, limitations and ethics, and proposed experiment plan.
- Data-derived distribution charts, reproducible summary generation, validation script, checksum inventory, and GitHub Actions validation.
- Byte-identical archive of all five supplied original files.

### Validation notes

- Workbook and JSON agree across all 181 records.
- All 15 controlled linguistic-construction labels are represented.
- One source URL is shared by two distinct records and is retained without silent correction.
